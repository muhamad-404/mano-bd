# mano-birthday

A mobile-first, static, interactive birthday website for Mano. Built with Vue 3 + Vite and deployed to GitHub Pages. No backend.

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Local Vite dev server |
| `npm run dev:mobile` | Prints LAN URL(s) + QR, then starts Vite with host |
| `npm run dev:https` | Same as mobile, over HTTPS (needed for mic on a phone) |
| `npm run build` | Production build to `dist/` |
| `npm run preview:mobile` | Build, print LAN URL + QR, preview with host |
| `npm run deploy:manual` | Push `dist/` via gh-pages (optional; Actions is preferred) |

## Test on your phone

1. Phone and computer on the same Wi-Fi.
2. Run `npm run dev:mobile`.
3. Scan the QR code or open the printed LAN URL.
4. For microphone features (candle blow), use `npm run dev:https` instead. The first visit shows a self-signed certificate warning; that is expected for the local cert and safe to accept for your own machine.

## Deploy

1. In the GitHub repo: Settings → Pages → Source → **GitHub Actions**.
2. Push to `main` (or run the workflow manually). The workflow builds with `VITE_BASE` set to `/<repo-name>/` and deploys Pages.

## Deploy checklist

1. Create a GitHub repository with a **non-obvious name** (the site will be public on a free plan).
2. Confirm you are on the correct GitHub account and that local `git` user/email are the ones you intend.
3. Push `main` to that repository (`git push -u origin main`).
4. Open **Settings → Pages → Source** and choose **GitHub Actions**.
5. Wait for the Deploy workflow to finish on the Actions tab.
6. Open `https://<user>.github.io/<repo>/` on your phone and walk through gate → start → finale.
7. Add `public/audio/bgm.mp3` and optional `public/audio/voice-note.mp3` before sharing the link if you want music and a voice note.

## Audio files

Put music and optional voice notes in `public/audio/` (for example `bgm.mp3`, `voice-note.mp3`). Add them by hand; they are not generated by the build.
